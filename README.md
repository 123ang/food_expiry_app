# Food Expiry Tracker

![App Logo](./FoodExpiryApp/assets/icon.png)

## Overview

Food Expiry Tracker is a comprehensive mobile application designed to help users reduce food waste by tracking expiration dates of food items. The app provides intuitive organization, timely notifications, and multilingual support to make food management effortless.

## Key Features

### 📱 User-Friendly Interface
- **Dashboard Overview**: At-a-glance view of upcoming expirations
- **Calendar View**: Visual timeline of when items expire
- **List View**: Sortable, filterable list of all food items
- **Dark & Light Themes**: Comfortable viewing in any environment

### 🗂️ Smart Organization
- **Categories System**: Organize foods by type (vegetables, fruits, dairy, etc.)
- **Location Tracking**: Group items by storage location (fridge, freezer, pantry)
- **Quick Setup**: Themed category sets for rapid onboarding
- **Custom Categories**: Create personalized organization systems

### ⏰ Notifications & Reminders
- **Expiry Alerts**: Configurable notifications before food expires
- **Priority Levels**: Set importance based on item value
- **Custom Schedules**: Control when and how you receive alerts

### 📷 Visual Management
- **Photo Capture**: Take pictures of items for easy identification
- **Visual Browsing**: Thumbnail previews in lists and details
- **Image Gallery**: Review all food items visually

### 🌐 Multilingual Support
- **5 Languages**: English, Thai, Chinese, Malay, and Japanese
- **Complete Translations**: Full interface and content localization
- **Dynamic Language Switching**: Change languages without data loss

### 📊 Food Waste Tracking
- **Usage Statistics**: Track consumed vs. discarded items
- **Waste Reduction Insights**: Learn patterns to minimize waste
- **History Records**: Review past item management

### 🔄 Data Management
- **Backup & Restore**: Protect your data
- **Import/Export**: Transfer data between devices
- **Privacy-Focused**: All data stored locally on your device

## Technical Highlights

### Architecture
- **React Native**: Cross-platform native performance
- **SQLite Database**: Robust local data storage
- **Context API**: Efficient state management
- **Expo Framework**: Streamlined development and deployment

### Performance Optimizations
- **Efficient Caching**: Minimizes database queries
- **Lazy Loading**: Fast app startup and navigation
- **Image Optimization**: Reduced storage footprint

### Multilingual System
- **Translation Key Architecture**: Dynamic content localization
- **Efficient Language Switching**: No database rewrites on language change
- **Backwards Compatibility**: Supports legacy data formats

### Offline-First Design
- **No Internet Required**: Fully functional without connectivity
- **Local-First Data**: All processing happens on device
- **Battery Efficient**: Optimized for mobile use

## Getting Started

1. **Install the App**: Download from the App Store or Google Play
2. **Quick Setup**: Choose category themes that match your needs
3. **Add Your First Items**: Start tracking with name, expiry date, and optional photo
4. **Set Notifications**: Configure when you want to be alerted
5. **Explore Views**: Try calendar, list, and category views to find your preference

## Privacy & Data

- **No Account Required**: Start using immediately without registration
- **No Cloud Storage**: All data stays on your device
- **No Tracking**: No analytics or user behavior monitoring
- **Optional Backups**: Create local backups to prevent data loss

## About the Project

Food Expiry Tracker was developed with a focus on sustainability and reducing global food waste. By helping individuals manage their food inventory more effectively, we aim to contribute to environmental conservation and household budget optimization.

The application is designed to be accessible to users worldwide with its multilingual support and intuitive interface that requires minimal learning curve.

## Recent Improvements

### Enhanced Multilingual Support
- **Translation Key System**: Categories and locations now use translation keys instead of storing translated text directly
- **Efficient Language Switching**: Changing languages no longer requires database rewrites
- **Complete Translations**: All UI elements and content fully translated in all supported languages

### Performance Optimizations
- **Reduced Startup Time**: Optimized database initialization and caching
- **Efficient Image Handling**: Better compression and storage of food item photos
- **Targeted Cache Invalidation**: Only refreshes necessary data when language changes

### User Experience Enhancements
- **Quick Setup Themes**: Intelligent detection of existing categories prevents duplicates
- **Improved Category Management**: Better organization of food types
- **Enhanced Calendar View**: More intuitive display of expiring items
